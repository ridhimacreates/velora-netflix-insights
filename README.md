# VELORA — Netflix Content Analysis & Recommendation System

VELORA is a data analytics and content discovery web application built using Python and Streamlit. It explores Netflix's catalogue through interactive visualizations, content filters, and a content-based recommendation system.

## Features
- Netflix catalogue overview and key statistics
- Movies vs TV Shows analysis
- Content trends by year
- Genre, country, rating, director, and cast analysis
- Search and filter functionality
- Content discovery
- Similar-title recommendations using TF-IDF and Cosine Similarity

## Tech Stack
- Python
- Streamlit
- Pandas
- Plotly
- Scikit-learn
- Power BI

## Recommendation System
VELORA uses a content-based filtering approach. It analyses available metadata such as genres, descriptions, directors, and cast to identify titles with similar characteristics.

## Project Purpose
This project aims to explore data analytics, data visualization, and recommendation techniques through an interactive platform for discovering insights from Netflix's content catalogue.
